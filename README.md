# 🚀 Overview

**Polaris Retirement Planner** is a modern retirement planning application that helps people understand how today's financial decisions influence tomorrow's retirement.

Rather than simply producing pension projections, Polaris guides users through the important retirement decisions, helping them understand:

- When they can afford to retire
- How much retirement income they may need
- Whether they are on track
- How long their pension could last
- The impact of changing contributions, retirement age and spending
- The trade-offs between different retirement strategies

The goal is simple:

> **Transform retirement planning from a collection of numbers into a clear story about your future.**

# 🎯 Design Philosophy

Polaris is built around a small number of principles.

## Ask questions, not technical settings

Rather than asking users to configure financial calculations directly, Polaris asks the questions people naturally ask about retirement and performs the calculations behind the scenes.

---

## Explain every number

Every important calculation should be understandable.

No unexplained projections.

---

## Build confidence

Planning for retirement should reduce uncertainty, not increase it.

---

## Encourage experimentation

Users should feel comfortable exploring different retirement decisions without affecting their primary plan.

---

## One source of truth

Every page works from the currently active retirement scenario.

# 🚀 Getting Started

Clone the repository

```bash
git clone https://github.com/JellyMaster/Retirement-Planner.git
```

Install dependencies

```bash
npm install
```

Run the development server

```bash
npm run dev
```

Create a production build

```bash
npm run build
```
