# Why Polaris Exists

Retirement planning is one of the most important financial journeys most people will ever undertake.

Yet today it is often fragmented across:

- Pension provider websites
- Investment platforms
- Spreadsheets
- Mortgage calculators
- Retirement calculators
- Financial advice

Most tools answer only one question.

Polaris exists to answer the bigger question:

> **"Am I on the right path towards the retirement I want?"**

---

# Our Mission

> **To help people understand retirement well enough to make confident financial decisions throughout their lives.**

Polaris is not designed to replace financial advice.

It is designed to help people become better informed before they make important decisions.

Understanding leads to confidence.

Confidence leads to better decisions.

---

# Our Philosophy

Retirement planning should be:

- Understandable
- Transparent
- Educational
- Flexible
- Encouraging

Never intimidating.

Never overwhelming.

Never filled with unexplained numbers.

Every chart.

Every recommendation.

Every experiment.

Every calculation.

Should answer one simple question:

**Why?**

---

# The Problem We're Solving

Traditional retirement calculators often ask for a few numbers and return a single projection.

Examples:

```
You will have

£642,000

at retirement.
```

That number is useful.

But it doesn't explain:

- Why?
- What assumptions were used?
- How sensitive is it?
- What if I save more?
- What if I retire later?
- What if markets fall?
- What should I change?

Polaris aims to answer all of those questions.

---

# A Different Approach

Rather than producing a single retirement number,

Polaris tells the story behind the plan.

```
Today's Decisions

↓

Future Outcomes

↓

Understanding

↓

Confidence
```

The application should guide users through the reasoning behind every important financial decision.

The focus of Version 1.x is to establish a best-in-class retirement planning experience.

# Vision for Version 2.x

Goals include:

- Secure user accounts
- Cloud synchronisation
- Shared plans

- Secure backup

# Vision for Version 3.x

Version 3 represents the long-term ambition.

# Artificial Intelligence

Artificial Intelligence should never replace understanding.

Instead it should improve it.

Possible future capabilities include:

Explain projections.

Highlight risks.

Recommend experiments.

Identify planning opportunities.

Generate plain-English summaries.

Predict the impact of future decisions.

AI should always explain its reasoning.

---

Users own their retirement data.

Polaris should always prioritise:

- Privacy
- Transparency
- Portability

# Accessibility Vision

Accessibility should continue to evolve alongside functionality.

- WCAG AA compliance

- Larger touch targets

# Education

Education is one of Polaris' defining features.

Rather than presenting generic financial articles,

Polaris should teach retirement concepts using the user's own retirement plan.

Immediate

Practical

# Simplicity

One of the biggest risks as Polaris grows is feature overload.

Future development should continually ask:

Does this make retirement easier to understand?

If not,

it probably doesn't belong.

---

# Success

- Number of features
